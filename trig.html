三角函數計算式

cos θ (餘弦) = 鄰邊 / 斜邊
= x / r = 1.000 / 1.000 = 1.000
sin θ (正弦) = 對邊 / 斜邊
= y / r = 0.000 / 1.000 = 0.000
tan θ (正切) = 對邊 / 鄰邊
= y / x = 0.000 / 1.000 = 0.000
單位圓的半徑 r = 1，因此座標 (x, y) = (cos θ, sin θ)。
